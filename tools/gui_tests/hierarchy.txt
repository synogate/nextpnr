# Hierarchy dock (open on the left by default; View > Hierarchy) on a flattened design with hierarchy
# (designs/hier_top.v): the instance tree (cells put into instances by the names of their nets), utilisation per
# instance, colouring the cells of instances in the device view, the filter, the Cells tab showing the cells of
# the selected instance; the same instances after saving and loading the placed design (the JSON keeps the other
# names of the nets).
# design: hier
resize 1400 1000
delay 600

dock hierarchyTree
dock hierarchyUsage
action Pack
waitidle
action Place
waitidle
delay 800
assert_label hierarchyHeader 3 instances
assert_label hierarchyStats placed

zoomfit

dock hierarchyUsage

shot 03_cells_of_u_cnt.png

settext hierarchyFilter fast

dock hierarchyTree
