# Exceptions tab (beside Clocks): the timing exceptions of the SDC file with the paths they match and apply to,
# and in the Paths tab how the slacks of a path come about (required time from the clock and the multicycle path,
# arrival time, the constraints on it). designs/multicycle.v with designs/multicycle.sdc: line 2 a multicycle
# path overridden by the more specific one of line 3 (setup 2) and line 4 (hold 1), line 5 a false path (its
# paths have no slacks).
# design: multicycle
resize 1600 1000
delay 600
# before packing: the exceptions are there, their paths not yet
tab Exceptions
assert_label exceptionSummary not packed
action Pack
waitidle
action Place
waitidle
delay 400
tab Exceptions
assert_label exceptionSummary 4 timing exception(s)
assert_label exceptionSummary The paths of a false path are not timed
dock exceptionList
shot 01_exceptions.png
# the multicycle path of line 3 applies to the paths from the operands
dock exceptionList set_multicycle_path 2 -setup
dock exceptionPaths

assert_label exceptionPathSummary line 2: set_multicycle_path 4
assert_label exceptionPathSummary overridden by line 3
